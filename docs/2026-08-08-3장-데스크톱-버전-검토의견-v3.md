## 2. 스킬 안내 문서를 고쳐야 했던 이유

교수님이 C-1 을 반영해 **노트 3.3.3 에서 이 문서를 링크하셨다.** 그런데 그 문서의 설치 안내가 사실과 달랐다. **틀린 안내가 학생에게 연결될 뻔했다.**

| 앞 판 | 실제 |
|---|---|
| "데스크톱 앱만 깔아도 CLI 가 보통 함께 들어온다" | **아니다.** `brew install --cask claude` 의 설치 항목은 `Claude.app` 하나뿐이고, CLI 는 `claude-code` 라는 **별개 cask** 다 |
| 대안으로 `npm install -g @anthropic-ai/claude-code` | 노드JS 가 필요한데, **노트 3.4.1 이 "노드JS를 사용하지 않고" 라고 못 박은 것과 부딪힌다** |

**고친 방향은 명령을 늘리는 것이 아니라 없애는 쪽이다.**

> **"superpowers 플러그인을 설치해 줘."**

`claude plugin ...` 은 슬래시 명령이 아니라 셸 명령이라 **클로드가 대신 실행할 수 있다.** CLI 가 없으면 그것부터 깔아 주고, 운영체제도 알아서 가른다. 제가 확인한 것은 이렇다.

- 세션 안에서 `claude plugin list` 가 정상으로 돈다
- `install`, `marketplace add` 에 대화형 확인이 없다
- `/opt/homebrew/bin` 에 쓰기 권한이 있어 **sudo 가 필요 없다**

**노트 `a.5.6) 클로드에게 요청하면 해결됨` 이 "명령을 외울 필요는 없습니다" 라고 해 놓고 스킬 설치만 명령 네 줄을 외우게 하던 모순도 함께 없어졌다.**

### C-3. `pip install torch` 만으로는 앱이 안 돈다 — **고쳤음**

> **📍 위치** — `3.3` ▸ **`3.3.4 최종 작업 결과가 저장된 깃허브 저장소`**
> **🔍 검색어** — `pip install torch`

v2 의 B-신4 에서 제가 제안하고 교수님이 반영하신 문장에 빠진 것이 있었다. **`pip install torch` 만으로는 `app.py` 가 안 돈다.**

`torch` 의 의존성 목록에 **`pillow` 가 없다**(`filelock, fsspec, jinja2, networkx, setuptools, sympy, typing-extensions`). 그런데 `app.py:14` 가 `from PIL import Image, ImageDraw` 를 쓴다. 그대로 따라 한 학생은 **`ModuleNotFoundError: No module named 'PIL'`** 을 만난다.

| 무엇을 하려면 | 필요한 것 |
|---|---|
| `python3 app.py` (학습 없이 실행) | `torch` **+ `pillow`** |
| `python3 train.py` (재학습) | `torch` + `torchvision` (`pillow` 가 딸려 온다) |

`tkinter` 는 표준 라이브러리라 따로 깔 것이 없다.

**노션의 해당 문장을 `pip install torch pillow` 로 고쳤고, 저장소 `README.md` 에도 표로 정리했다.**

## 6. 확인 방법

**직접 확인한 것**

- 노션 노트를 다시 내려받아 v2 판과 줄 단위로 대조했다. 그림은 캐시를 써 **119장 중 1장만 새로 받았다.**
- **학습 시간은 실제로 두 번 돌려 쟀다.** MPS 50.12초, CPU 89.91초. 원본 가중치의 SHA-256 이 작업 전후로 같은 것을 확인했다.
- **`brew info` 로 두 cask 를 대조**해 `claude` 는 앱만, `claude-code` 는 CLI 를 설치하는 것을 확인했다.
- 노션 수정 뒤 다시 내려받아 **코드 블록 언어 분포, 캡션 4곳, 링크 2곳, 그림 119장 유지**를 하나씩 대조했다.
- **이미지 교체가 안 되는 것**은 추론이 아니라 시험해 확인했다. 서명이 fetch 마다 다르고, 고정 경로로도 `No matches found` 였다.
- v3 의 검색어는 전부 **본문 글자**로 골랐다. 그림 안 글자는 노션 검색에 안 걸린다.

**확인하지 못한 것**

- **윈도우에서 아무것도 시험하지 못했다.** ZIP 의 한글 파일명 처리, `py` 명령, `winget` 설치 경로가 그렇다. **수업 전에 윈도우 PC 한 대에서 처음부터 밟아 보시기를 권한다.** 세 판에 걸쳐 같은 말을 적고 있는데, 제가 메울 수 없는 유일한 구간이다.
- **빈 맥에서 스킬 설치를 처음부터 돌려 보지 못했다.** 각 명령이 비대화형이고 sudo 가 필요 없다는 것까지만 확인했다.
- **가림 처리한 그림을 노션에 넣어 본 것은 아니다.** 파일만 만들었다.

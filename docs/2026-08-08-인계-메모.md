
### ③ 스킬 설치 안내가 CLI 를 전제하는데 수업은 CLI 를 안 깐다 (B 등급)

> **📍 위치** — 노션이 아니라 **`docs/2026-08-07-스킬-사용-현황과-설치-안내.md`** 129줄, 132줄
> **🔍 검색어** — `보통 함께 들어오지만`

**확인한 사실이다.** brew 가 각 cask 에서 설치하는 것을 직접 대조했다.

| 명령 | Artifacts |
|---|---|
| `brew install --cask claude` (노트 `3.1.1.1 c.2`) | **`Claude.app` (App)** — 앱뿐 |
| `brew install --cask claude-code` | **`claude` (Binary)** — CLI. **별개 cask** |

`/Applications/Claude.app/Contents/MacOS/` 에는 `Claude` 하나뿐이고 CLI 도 PATH 링크도 없다. **그러니 문서 129줄의 "데스크톱 앱만 깔아도 보통 함께 들어오지만" 은 사실이 아니다.** 3.1.1 만 따라 한 학생에게 `claude` 명령은 없다.

**더 나쁜 것은 132줄의 대안이 `npm install -g @anthropic-ai/claude-code` 라는 점이다.** 노트 `3.4.1` 이 "노드JS를 사용하지 않고" 라고 적어 둔 것과 정면으로 부딪힌다. 일부러 걷어낸 노드JS 를 되살린다.

**고칠 것 — 명령 목록을 지우고 말 한마디로 바꾼다.**

`claude plugin ...` 은 슬래시 명령이 아니라 **셸 명령**이다. 데스크톱 앱의 클로드도 Bash 를 쓸 수 있으므로(노트 그림 044, 047 에서 `pwd; ls -la; which python3` 를 돌리는 것이 증거다) **클로드가 대신 실행할 수 있다.** 즉 학생은 명령을 한 줄도 칠 필요가 없다.

> **"superpowers 플러그인을 설치해 줘."**

확인한 것은 이렇다.

| 검사 | 결과 |
|---|---|
| 세션 안에서 `claude plugin list` 실행 | 정상. 출력하고 바로 끝난다 |
| `claude plugin install` 옵션 | `--config`, `--scope`, `-h` 뿐. **대화형 확인 없음** |
| `claude plugin marketplace add` | 마찬가지로 비대화형 |
| `/opt/homebrew/bin` 쓰기 권한 | 있음 → `brew install --cask claude-code` 에 **sudo 불필요** |

**운영체제도 클로드가 알아서 가른다.** 윈도우면 brew 대신 맞는 방법을 쓴다. 윈도우용 CLI 설치 명령을 확인하지 못한 것이 이 방식에서는 문제가 되지 않는다.

**이쪽이 이 수업의 메시지와도 맞는다.** 노트 `a.5.6) 클로드에게 요청하면 해결됨` 이 "명령을 외울 필요는 없습니다" 라고 해 놓고, 스킬 설치만 명령 네 줄을 외우게 하고 있었다.

**남는 것은 재시작 하나다.** 플러그인은 세션 시작 때 읽히므로 설치 후 껐다 켜야 스킬이 보인다. 이건 클로드가 대신 못 하니 안내에 남긴다.

**플러그인은 `~/.claude/plugins/` 에 들어가고 데스크톱 앱과 CLI 가 그 폴더를 공유한다.** 그래서 한 번 깔아 두면 그 뒤 실습은 데스크톱 앱에서 그대로 된다. 이 프로젝트가 증거다 — 노션 그림 090 의 `스킬 실행됨 /superpowers:writing-plans` 는 데스크톱 앱 Code 모드 세션에서 찍혔고 세션 기록에서도 확인된다.

**아직 확인 못 한 것**

- **CLI 가 아예 없는 맥에서 이 흐름을 처음부터 돌려 보지 못했다.** 이 맥에는 이미 깔려 있다. 각 명령이 비대화형이고 sudo 가 필요 없다는 것까지만 확인했다.
- 데스크톱 앱 **자체 화면**에서 플러그인을 설치할 수 있는지. 위의 말로 하는 방식이 있으므로 급하지는 않다.

## 여전히 판단이 필요한 것 (이전 세션에서 넘어옴)

- **`logistex/study01_MNIST`**(소문자 `s`) 세 번째 저장소. 사용자가 **"그냥 둬"** 라고 했다
- **`.env` 의 토큰 폐기.** 값이 대화 기록에 남았고 `gh` 는 키체인으로 동작한다. 폐기를 권했으나 미결
- **`.env` 위치.** Synology Drive 로 동기화되므로 사본이 클라우드에 올라간다

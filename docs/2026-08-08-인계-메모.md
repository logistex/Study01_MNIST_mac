## 노션 그림 캐시 — 다음 검토 때 반드시 쓴다

**사용자가 명시적으로 요청한 것이다. "매번 검토할 때마다 그림을 중복해서 다운로드하지 않도록 해줘."**

캐시는 `~/.cache/notion그림/3장-데스크톱/` 에 있다(120개, 19MB). 저장소가 아니라 홈 아래에 둔 이유는 Synology Drive 동기화와 git 을 피하기 위해서다.

**키는 S3 주소 경로 가운데의 UUID(첨부 블록 ID)다.** 서명은 매번 바뀌지만 이 UUID 는 그림마다 고정이다. 이번 재검토에서 **118장 중 5장만 새로 받았다.**

절차는 `docs/도구/README.md` 에 있다. 요약하면 이렇다.

```bash
python3 docs/도구/그림캐시.py sync <노션원본.txt> <작업폴더/img>
python3 docs/도구/읽기용만들기.py <노션원본.txt> <작업폴더>
```

**`notion-fetch` 결과가 24만 자라 컨텍스트에 안 들어간다.** 클로드 코드가 알아서 파일로 떨구고 경로를 알려 주므로 그 파일을 쓰면 된다. 억지로 읽으려 하지 않는다.

## 환경에서 알아 둘 것

**`gh` 인증은 macOS 키체인을 쓴다.** `.env` 의 `GITHUB_TOKEN` 을 `source` 하면 `gh auth login` 이 막힌다. 평소에 부르지 않는다.

**MNIST 원본은 저장소에 없다.** 로컬 파일은 그대로다. 복구 절차는 `desktop_version/CLAUDE.md` 에 있으나 **빈 폴더에 클론해 끝까지 돌려 본 적은 없다.**

**히스토리에는 63MB 가 남아 있다.** 추적만 끊었으므로 원격 크기는 줄지 않는다.

**`/plugin`, `/permissions` 같은 터미널 대화 상자 명령은 이 환경에서 안 된다.** `claude plugin list` 처럼 터미널 명령을 쓴다.

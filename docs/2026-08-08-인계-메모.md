`claude plugin ...` 은 슬래시 명령이 아니라 **셸 명령**이다. 데스크톱 앱의 클로드도 Bash 를 쓸 수 있으므로(노트 그림 044, 047 에서 `pwd; ls -la; which python3` 를 돌리는 것이 증거다) **클로드가 대신 실행할 수 있다.** 즉 학생은 명령을 한 줄도 칠 필요가 없다.

> **"superpowers 플러그인을 설치해 줘."**

확인한 것은 이렇다.

| 검사 | 결과 |

**플러그인은 `~/.claude/plugins/` 에 들어가고 데스크톱 앱과 CLI 가 그 폴더를 공유한다.** 그래서 한 번 깔아 두면 그 뒤 실습은 데스크톱 앱에서 그대로 된다. 이 프로젝트가 증거다 — 노션 그림 090 의 `스킬 실행됨 /superpowers:writing-plans` 는 데스크톱 앱 Code 모드 세션에서 찍혔고 세션 기록에서도 확인된다.

#### 가능한가 — 가능하다

`notion-update-page` 의 **`update_content`** 명령이 전체 교체가 아니라 **부분 검색-치환**(`content_updates` 배열, old_str/new_str, 최대 100쌍)을 지원한다. **`replace_content` 를 쓰면 안 된다** — 그림 118장과 5단 토글 구조가 날아갈 수 있다.

#### 규모 — 코드 블록 32개 중 31개를 바꾼다

현재 `javascript` 18개, `plain text` 14개다. 언어와 내용이 전혀 맞지 않는다.

| 바꿀 언어 | 개수 | 어떤 것 |
|---|---|---|
| **Bash** | 15 | `brew --version`, `/bin/bash -c "$(curl ...)"`, `echo >> ~/.zprofile`, `brew uninstall/install/upgrade --cask claude`, `npm install -g ...`, `brew install gh`, `gh auth login`, `gh auth status`, `git init`, `git add .`(2개), `git commit`(2개), `gh repo create`, `git push` |
| **PowerShell** | 8 | `winget --version`, `Invoke-WebRequest`, `Add-AppxPackage`, `winget uninstall/install/upgrade --id Anthropic.Claude`, `winget install --id GitHub.cli` |
| **Plain Text** | 8 | 프롬프트 전부(손글씨 인식 3종, 윈도우 바로가기, 웹/데스크톱 분리, 저장소 만들기, Pages 배포) |
| (그대로) | 1 | `현재 설정 → build_type: workflow` — 이미 `plain text` 다. **단 ① 에서 이 블록 자체를 손본다** |

#### 반드시 지킬 순서와 주의

1. **사용자의 노션 편집이 끝난 뒤에 한다.** 동시에 편집하면 부딪힌다.
2. **직전에 노트를 다시 fetch 한다.** `update_content` 는 old_str 이 **정확히** 일치해야 한다. 사용자가 A-신2(`getwinget` 공백)를 고치면 그 블록의 내용이 바뀌므로 옛 fetch 로 만든 old_str 은 안 맞는다.
3. **`notion://docs/enhanced-markdown-spec` 을 먼저 읽는다.** 노션이 받는 언어 이름 표기를 추측하지 않는다(fetch 결과에는 `javascript`, `plain text` 로 소문자였다).
4. **`git add .` 는 문서에 두 번 나온다.** 둘 다 Bash 이므로 `replace_all_matches: true` 로 처리한다. 나머지는 내용이 유일하다.
5. **백업.** `notion-duplicate-page` 로 사본을 뜨거나, 노션 자체 **페이지 기록**으로 되돌릴 수 있음을 사용자에게 알린다.
6. **작업 후 다시 fetch 해서 32개가 의도대로 바뀌었는지 대조한다.** 그림 수가 118장 그대로인지도 함께 센다.

`데스트톱` 은 두 곳 다 고치므로 `replace_all_matches: true` 로 한 번에 된다. 정상 표기 `데스크톱` 은 문서에 24번 나오는데 **`데스트톱` 과 겹치지 않으므로 안전하다.**

**주의** — 세 번째 항목은 **B-신1 이 토글 제목 자체를 다시 쓰라고 제안한 자리다.** B-신1 을 먼저 반영하면 이 오타는 저절로 없어진다. 순서를 확인하고 중복 작업을 피한다.

### ⑥ 그림 039 의 캡션을 맥 경로로 고친다 — **클로드가 직접 수행** (C 등급)

> **📍 위치** — `3.1 클로드 데스크톱 설치` ▸ `3.1.2 클로드 CLI 버전 설치 및 실행 (참고용)` ▸ **`c) 맥`** ▸ `c.2) 클로드 실행`
> **🔍 검색어** — `c.2) 클로드 실행`

사용자가 직접 수행을 지시했다(2026-08-08). 캡션의 `"C:\Users\logistex"` 를 `"/Users/사용자이름"` 으로 바꾼다.

#### 함정 — 같은 캡션이 두 군데 있고 하나는 고치면 안 된다

| 그림 | 절 | 캡션 | 판정 |
|---|---|---|---|
| 027 | `3.1.2` ▸ **`b) 윈도`** ▸ `b.2) 클로드 실행` | `(터미널에서 "claude" 입력하고 엔터)<br>("C:\Users\logistex" 폴더를 신뢰한다면 1 입력하고 엔터)` | **맞다. 건드리면 안 된다** |
| 039 | `3.1.2` ▸ **`c) 맥`** ▸ `c.2) 클로드 실행` | **글자까지 완전히 같다** | **틀렸다. 이것만 고친다** |

**`replace_all_matches: true` 를 쓰면 맞는 캡션까지 망가진다.** old_str 에 앞의 토글 제목(`<summary>c.2) 클로드 실행</summary>`)을 붙여 039 만 집는다.

**캡션은 `![캡션](주소)` 형태라 이미지 주소 바로 앞에 있다.** old_str 을 `<summary>c.2) 클로드 실행</summary>` 부터 캡션 끝 `]` 까지로 끊으면 **매번 바뀌는 서명 주소를 포함하지 않아도 된다.** 이것이 캡션을 안전하게 고치는 요령이다.

같은 절의 그림 040 캡션(`종료하려면 'quit' 입력`)은 **C-신4** 에서 `/exit` 으로 바꿔야 하므로 함께 처리하면 좋다.

## 클로드가 노션을 직접 고칠 때의 공통 규칙

④ ⑤ ⑥ 에 모두 적용된다. **사용자가 직접 수행을 지시한 작업이 늘고 있으므로 여기에 모아 둔다.**

1. **`replace_content` 를 쓰지 않는다.** 반드시 `update_content` 의 부분 치환이다. 전체 교체는 그림 118장과 5단 토글을 날릴 수 있다.
2. **사용자의 편집이 끝난 뒤에 한다.** 동시 편집은 부딪힌다.
3. **직전에 노트를 다시 fetch 한다.** old_str 은 정확히 일치해야 하고, 사용자가 고친 곳은 옛 fetch 와 다르다.
4. **`notion://docs/enhanced-markdown-spec` 을 먼저 읽는다.** 노션 마크다운 문법을 추측하지 않는다.
5. **일괄 치환 전에 문서에서 몇 번 나오는지 센다.** ⑥ 처럼 맞는 것과 틀린 것이 같은 글자인 경우가 있다.
6. **백업.** 노션 **페이지 기록**으로 되돌릴 수 있음을 알리고, 큰 작업이면 `notion-duplicate-page` 로 사본을 뜬다.
7. **작업 후 다시 fetch 해서 대조한다.** 의도한 곳만 바뀌었는지, **그림이 118장 그대로인지** 센다.

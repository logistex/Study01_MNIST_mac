# 검토용 도구

노션 강의 노트를 검토할 때 쓰는 스크립트 세 개다.

## 노션 노트 검토 순서

### 1. 노션 문서를 내려받는다

`notion-fetch` 로 페이지를 가져온다. 결과가 24만 자라 컨텍스트에 다 들어가지 않는다. **클로드 코드는 이 경우 결과를 자동으로 파일에 떨궈 주고 그 경로를 알려 준다.** 그 파일을 쓰면 된다.

### 2. 그림을 캐시와 맞춘다

```bash
python3 docs/도구/그림캐시.py sync <노션원본.txt> <작업폴더/img>
```

**같은 그림을 두 번 내려받지 않는다.** 노션이 주는 S3 주소는 300초 만에 만료되고 서명이 매번 바뀌지만, 경로 가운데의 UUID(첨부 블록 ID)는 그림마다 고정이라 그것을 캐시 키로 쓴다.

```
https://prod-files-secure.s3.../{워크스페이스}/{첨부UUID}/{파일명}?X-Amz-...
                                              ^^^^^^^^^^ 캐시 키
```

캐시는 `~/.cache/notion그림/3장-데스크톱/` 에 있다. **저장소가 아니라 홈 아래에 두었다.** 19MB 라 Synology Drive 로 동기화할 이유가 없고, git 에 올릴 것도 아니다.

- 2026-08-08 재검토 때 그림 118장 중 **5장만 새로 받았다.** 나머지 113장은 캐시에서 썼다
- 새로 받을 것이 있으면 `xargs -P 30` 으로 병렬 처리한다. 순차로 받으면 서명 만료로 중간부터 전부 `AccessDenied` 가 난다
- 작업 폴더에는 하드링크를 건다. 용량을 두 배로 쓰지 않는다

### 3. 본문을 읽을 수 있는 크기로 줄인다

```bash
python3 docs/도구/읽기용만들기.py <노션원본.txt> <작업폴더>
```

그림 주소가 전체의 83%다. 걷어내면 24만 자가 4만 자로 줄어 전문을 읽을 수 있다. 두 파일이 나온다.

| 파일 | 내용 |
|---|---|
| `읽기용.md` | 본문. 그림은 `[그림 NNN \| 캡션]` 으로 바뀌고 번호가 `img/NNN.png` 와 맞는다 |
| `그림위치.tsv` | 그림마다 토글 경로와 캡션. **검토 의견서의 📍 위치 를 뽑을 때 쓴다** |

### 4. 이전 판과 그림을 대조한다

번호가 밀리므로 옛 번호와 새 번호의 대응을 먼저 계산한다. 그러면 **무엇이 새로 들어왔고 무엇이 빠졌는지**만 보면 되므로 검토가 빨라진다.

## 마크다운을 PDF 로

```bash
python3 docs/도구/md2pdf.py 입력.md 출력.pdf
```

pandoc, weasyprint 가 없어 마크다운 → HTML → 크롬 헤드리스 인쇄로 만든다. 주의점 둘.

- **중첩 코드펜스(4중 백틱)를 쓰면 안 된다.** 파이썬 markdown 이 처리 못 해 PDF 에 백틱이 그대로 노출된다
- **블록인용 안의 코드펜스도 안 된다.** 한 줄로 뭉개진다. 인용을 끊고 펜스를 밖에 두면 된다

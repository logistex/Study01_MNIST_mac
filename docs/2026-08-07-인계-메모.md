병합 시 의도적으로 미룬 지적들이다. **급한 것은 없다.**

1. `web_version/모델.js` — `가중치.bin` 길이가 4의 배수가 아니면 `new Float32Array(버퍼)` 가 네이티브 `RangeError` 를 던진다. `byteLength % 4` 선검사
2. `web_version/모델.js` — `소프트맥스` 의 `Math.max(...점수)` 가 배열을 스택에 펼친다. 지금은 원소 10개라 안전
3. `web_version/검증.html` — 순전파 검사가 정규화 식을 인라인 복제. `전처리.js` 의 `정규화` 로 대체
4. `web_version/검증.html` — 전처리가 `null` 이면 조기 `return` 이라 요약 줄이 안 나옴
5. `web_version/전처리.js` — `면적평균축소` 의 `넓이합 > 0 ?` 가드 제거 가능 (5,600조합 전수 확인)
6. `web_version/앱.js` — "모델을 불러오는 중입니다..." 말줄임표가 문체 규칙과 충돌. **판단 필요**
7. `web_version/앱.js` — 적재 중 그린 그림이 완료 후 자동 인식되지 않음
8. `web_version/index.html` — `file://` 로 열면 CORS 로 조용히 멈춤. `onerror` 안내를 붙일지는 **실제 Chrome 으로 확인 후 판단**
9. `desktop_version/검증데이터만들기.py` — **표본 편향.** 아홉 중 값이 가장 크다

**9번은 이제 `desktop_version/CLAUDE.md` 에 정식으로 기록됐다.** 이 메모를 지워도 사라지지 않는다.

## 환경에서 알아 둘 것

**`gh` 인증은 macOS 키체인을 쓴다.** `~/.zshrc` 의 `GITHUB_TOKEN` 은 제거됐다. **`.env` 를 `source` 하면 그 문제가 되살아난다.** 평소에 부르지 않는다.

**MNIST 원본은 저장소에 없다.** 로컬 파일은 그대로다. 복구 절차는 `desktop_version/CLAUDE.md` 에 있으나 **빈 폴더에 클론해 끝까지 돌려 본 적은 없다.**

**히스토리에는 63MB 가 남아 있다.** 추적만 끊었으므로 원격 크기(26MB)는 줄지 않는다. 히스토리 재작성은 위험 대비 이득이 적다고 보고 하지 않았다.

**설치된 플러그인 7개 중 이 프로젝트에 쓰인 것은 `superpowers` 뿐이다.** 나머지 여섯은 한 번도 호출되지 않았다.

**`/plugin` 슬래시 명령은 이 환경에서 안 된다.** `claude plugin list` 처럼 터미널 명령을 쓴다.
